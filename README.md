# BMA0403 – Biosensors Assessment Projects

A collection of MATLAB-based simulations completed as part of the
B.E. Biomedical Engineering Biosensors coursework at SIMATS.

## Assessment Tools

### CO3 AT2 – Circuit Simulation and Design
- Inverting amplifier
- Signal digitization
- Wheatstone bridge strain sensor
- Biosensor noise analysis
- Sensor calibration

### CO3 AT3 – Design Project Simulations
- Smart light intensity measurement
- Digital lux meter
- Spectral response analyzer
- Optical pulse detection
- Radiometric energy measurement
- Multi-sensor signal conditioning

### CO4 AT3 – Sensor Simulation Tasks
- Ultrasonic distance measurement
- Microwave Doppler sensor
- Capacitive proximity sensor
- Triboelectric energy harvesting
- Pressure gradient sensor

### CO5 AT2 – Nanotechnology-Based Sensor Simulations
- Density of States simulation
- 1D nanowire gas sensor
- Thin-film gas sensor
- Nano optical sensor
- Nano cantilever mechanical sensor
